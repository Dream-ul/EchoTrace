# Discourse workflow extensions

Use a recency-and-platform lens for “what people are saying” questions, while keeping authority-source research separate. Decompose the topic into primary/official context, counter-perspective, practitioner discourse, and time window. For each platform, record the search operator or adapter and retrieval date.

Represent discourse as original posts, comments, replies, quotes, and reposts. Cluster syndicated text before counting. Report independent origins separately from amplification and engagement. Snippets are discovery hints and untrusted data; fetch or preserve a locatable capture before treating a statement as evidence.

If the question is only a single URL lookup, use the fetch Tool directly. If the question asks for prevalence or factual truth, report sampling bias and hand factual leads to claim verification.
